BIRTHDAY SURPRISE - ready for Vercel
====================================
Folder structure:
  index.html
  style.css
  script.js
  images/        <- put your photos here (photo1.jpg ... photo4.jpg)

1) Edit the CONFIG block at the top of script.js (name, reasons, letter, photo captions).
2) Add your photos to the images/ folder.
3) Open index.html in a browser to test.
4) Deploy: upload this folder to a GitHub repo and import it in Vercel
   (Framework Preset: "Other", no build command, no output directory),
   or run "vercel" inside this folder with the Vercel CLI.
5) Share the Vercel link. She lands straight on the gift screen.
